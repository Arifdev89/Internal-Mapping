Indoor Navigation System

A Django-based indoor and outdoor navigation system designed to help users find buildings, rooms, and locations with route guidance.

Project Overview

This project combines GPS-based outdoor navigation with database-driven indoor navigation. It uses OpenStreetMap for building search and outdoor mapping, and a Django backend to manage indoor building layouts, floors, locations, and navigation routes.

The current indoor navigation development focuses on Vijaya Vittala Institute of Technology (VVIT).

Features

GPS-based outdoor location tracking.

Interactive map using Leaflet.

OpenStreetMap integration.

Building search and selection.

Indoor building and floor management.

Indoor floor maps using SVG.

Room and location identification.

Navigation nodes and edges stored in a database.

Shortest-path indoor routing using Dijkstra's algorithm.

Multi-floor navigation through staircase connections.

Database connection status monitoring.

QR-code-based indoor location support.
